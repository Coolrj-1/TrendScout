Privacy Policy

Last updated: November 27, 2026

This policy explains how TrendScout (https://trendscout.pages.dev/) handles information. TrendScout is an independent open-source project.

Information processed to operate the site

TrendScout displays public GitHub repository metadata such as repository names, descriptions, public URLs, stars, forks, languages, topics and update dates. The site does not currently require visitor accounts or provide visitor profiles, comments or a contact form.

The website is hosted on Cloudflare Pages. Cloudflare may process technical request information, such as IP address, browser and device details, requested URLs, timestamps and security events, to deliver and protect the website. See Cloudflare's Privacy Policy.

Analytics

TrendScout may enable Cloudflare Web Analytics through a site-owner configuration. If enabled, Cloudflare may process website usage and performance information. This policy should be updated if analytics configuration changes.

Advertising and cookies

Advertising is not currently represented as active on this site. If services such as Google AdSense are added, providers may use cookies, web beacons, IP addresses or similar technologies to serve, measure and personalize ads, subject to provider settings and applicable law. This policy and any required consent controls will be updated before advertising is activated. See how Google uses data on partner sites.

Third-party links

Links to GitHub and other third-party websites are governed by those services' own privacy policies. TrendScout does not control their data practices.

Changes and contact

This policy may be updated as the site changes. For privacy questions or corrections, contact the project maintainer through the TrendScout GitHub issue tracker. Do not post sensitive personal information in a public issue.
