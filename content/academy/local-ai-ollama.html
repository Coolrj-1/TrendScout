Run a local model with Ollama

Local inference lets you run supported language models on your own computer. It can reduce reliance on hosted chat services, but performance depends heavily on RAM, available memory, model size and hardware. Local does not automatically mean private if you connect external services or extensions.

What you'll need

  • A supported Windows, macOS or Linux system.
  • Enough free disk space and memory for the model you choose.
  • A model compatible with your hardware.

1. Install Ollama

Download the installer from the official site and follow its current platform-specific instructions.

Ollama downloads → · Ollama source →

2. Choose a model

Check the model library for size, license, context length and hardware guidance. Start with a small model; larger models may be too slow or fail to load on systems with limited memory.

Browse the model library →

3. Run a model

After installation, use the command shown on the model's library page. For example, the general pattern is:

ollama run MODEL_NAME

Replace MODEL_NAME with an exact model identifier from the official library. The first run may download several gigabytes.

4. Try a simple prompt

Ask the model to summarize a short paragraph or explain a small code sample. Compare speed and answer quality with a hosted model, but don't assume the same model names imply identical versions or behavior.

5. Manage resources and privacy

  • Monitor RAM, GPU memory and disk usage.
  • Stop models you no longer need using the documented commands for your version.
  • Keep the local service bound to trusted interfaces; don't expose it publicly without authentication and network controls.
  • Review model licenses before commercial use.

You've finished when…

You can run a model locally, send it a prompt and explain the hardware trade-offs of your chosen model.
