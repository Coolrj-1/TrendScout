Get started with OpenCode

OpenCode is an open-source AI coding agent that can inspect and edit a project through a terminal interface. This lesson covers a cautious first setup; provider availability, model names and commands can change, so use the official docs for current details.

What you'll need

  • A Windows, macOS or Linux computer.
  • A project folder you can safely experiment in (a copy or Git branch is ideal).
  • An account or API credentials for a provider supported by your OpenCode version.

1. Install OpenCode

Follow the official installation instructions for your operating system. Avoid third-party repackaged installers.

OpenCode official documentation → · Source repository →

2. Open a test project

Open a terminal in a disposable project or a clean Git branch. Start OpenCode using the command shown in its installed-version documentation.

git status

Confirm your working tree is clean before experimenting. If you're using PowerShell, run commands in your project directory.

3. Configure a provider

Use OpenCode's provider setup flow and follow the provider's official instructions. Never paste API keys into source files, screenshots, prompts shared publicly or Git commits. Prefer environment variables or the tool's supported secret storage.

4. Make a small first request

Ask the agent to explain the project structure or suggest a tiny documentation improvement before allowing broad edits. Review every proposed change and inspect the diff.

git diff

5. Keep control of actions

  • Do not approve commands you don't understand.
  • Don't give an agent access to passwords, private keys or unrelated folders.
  • Review dependency changes and network requests.
  • Commit only after tests and manual review.

You've finished when…

You can open a project, ask OpenCode to explain a file, review a suggested change and discard it safely if needed.
