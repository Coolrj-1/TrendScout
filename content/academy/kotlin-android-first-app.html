ANDROID · BEGINNER · 30–45 MINUTES

Build your first Kotlin Android app

This walkthrough gets a basic project running. Android Studio templates and Gradle versions change, so use the current Android developer documentation if the labels in your installation differ.

What you'll need

  • A computer that can run Android Studio.
  • Android Studio and its recommended SDK components.
  • An emulator or Android phone with developer options and USB debugging enabled if using a device.

1. Install Android Studio

Download Android Studio from the official Android developer site and complete its setup wizard.

Android Studio download → · Kotlin for Android →

2. Create a project

Choose New Project, select a simple phone/tablet template such as Empty Activity, choose Kotlin, set an application name and package identifier, then let Gradle sync finish.

3. Understand the project

  • app/ contains the application module.
  • src/main/ contains source and app resources.
  • AndroidManifest.xml declares app components and permissions.
  • Gradle files describe plugins, dependencies and build settings.

4. Run the starter app

Create an emulator using Device Manager or connect your own test phone. Select the target device and press Run. On a physical phone, only enable USB debugging on a device you control and revoke authorization when finished.

5. Make one small change

Change the starter screen text using the template's Kotlin UI code, then run the app again. If the project uses Jetpack Compose, the screen is commonly described with composable functions; XML-based templates use layout resources.

6. Build safely

  • Request only permissions your app genuinely needs.
  • Never commit signing keys, passwords or API tokens.
  • Test on more than one screen size where possible.
  • Read dependency licenses and keep libraries updated.

You've finished when…

Your app launches on an emulator or test phone and you can locate the Kotlin source that controls its first screen.
