What Are Model Context Protocol (MCP) Servers?

Model Context Protocol (MCP) is an open protocol for connecting AI applications to external tools and sources of context. An MCP server exposes capabilities that an MCP-compatible client can discover and use.

What can a server provide?

Depending on its implementation, a server may expose tools, resources or prompt templates. Examples include searching a knowledge base, querying an approved service, reading project files or interacting with a development tool.

How does it work?

An MCP-compatible host or client connects to a server, discovers its capabilities and makes selected capabilities available to the model. Transport and configuration depend on the client and server.

Evaluate before connecting

  • Check the source code, maintainer and release history.
  • Read the permissions and data access requested.
  • Use least-privilege credentials.
  • Be cautious with tools that write files, execute commands or access networks.
  • Test unfamiliar servers in a limited environment.
