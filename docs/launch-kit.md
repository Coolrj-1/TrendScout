## Positioning

TrendScout is an open-source GitHub project discovery dashboard. It scans public GitHub repository metadata across developer technology categories and helps people inspect projects using transparent signals such as stars, forks, language, topics, freshness and (when historical snapshots exist) measured seven-day star growth.

It is a discovery and research aid, not a quality, security or investment endorsement. TrendScout does not clone or execute repository code.
